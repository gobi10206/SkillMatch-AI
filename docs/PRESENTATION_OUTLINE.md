# Presentation Outline - SkillMatch AI (15-20 slides)

1. Title - SkillMatch AI: Inclusive Workforce Upskilling and Career Path Engine
2. Problem - job seekers can't articulate existing skills; opaque matching
3. Motivation - informal and volunteer experience is invisible to typical job portals
4. SDG Alignment - SDG 4, 8, 10 (one line each)
5. Existing System - keyword search job portals, black-box match scores
6. Proposed System - skill discovery to gap to learn to match to apply to track
7. Architecture - React PWA / FastAPI / PostgreSQL+pgvector / Redis diagram
8. User Journey - registration through application tracking, one flow diagram
9. AI/NLP Pipeline - keyword plus semantic extraction, evidence-backed, explainable
10. Skill Gap Engine - transparent weighted scoring, existing vs missing skills
11. Learning Recommendation - personalized, step-based, estimate-labeled durations
12. Job Matching - competency-only scoring, explainable match cards
13. Fairness - schema isolation, code-isolation test, fairness dashboard
14. Analytics - aggregated community dashboard, anonymization floor
15. Technology Stack - table with justification per layer
16. Live Demo - see DEMO_GUIDE.md script
17. Results - what's implemented and tested today
18. Future Scope - fine-tuned NER, real course APIs, i18n, mobile
19. Impact - projected vs measured, honestly framed
20. Conclusion - explainability and fairness as architecture, not add-ons
